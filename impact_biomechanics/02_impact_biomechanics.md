## 1. คุณกำลังตอบคำถามอะไร

> **ท่าปะทะ (tackle) แบบไหน ที่ความเร็ว/มุม/มวลเท่าไหร่ ส่งแรงเข้าสู่คอและศีรษะมากที่สุด — และทำนายล่วงหน้าได้ไหม**

คุณมองทั้งร่างกายเป็นระบบของแข็งต่อกันด้วยข้อ (multibody) ไม่ได้สนใจว่าเนื้อกระดูกข้างในเป็นยังไง — **นั่นเป็นงานคนที่ 1**

### ตัวแปร

| ประเภท | ตัวแปร |
|---|---|
| **ตัวแปรต้น** (input) | ความเร็วเข้าปะทะ, มุมปะทะ, มวลผู้เล่นทั้งสองฝั่ง, ท่าทางขณะปะทะ, ระดับการเกร็งกล้ามเนื้อคอ |
| **ตัวแปรตาม** (output) | joint reaction force, muscle force, head kinematics (ความเร่งเชิงเส้น + เชิงมุม) |

## 2. ⚠️ ขอบเขต — ห้ามล้ำเส้น

คุณกับคนที่ 1 ทำเรื่องรักบี้เหมือนกัน **ถ้าขอบเขตทับกัน ตีพิมพ์ได้แค่คนเดียว**

```
คุณ (การชนทั้งร่างกาย)  ──ส่งค่าแรงที่คำนวณได้──>  คนที่ 1 (กระดูกชิ้นเดียว)
```

| คุณทำ | คุณไม่ทำ (เป็นงานคนที่ 1) |
|---|---|
| ทั้งร่างกาย เป็นชิ้นแข็งต่อกัน | เนื้อกระดูกข้างใน |
| คำนวณว่าแรงมาจากไหน เท่าไหร่ | strain, stress, กระดูกแตกไหม |
| HIC, Nij, BrIC, ท่า tackle | mesh, FE, material property |

**แรงเป็น output ของคุณ = input ของคนที่ 1** คุณคือต้นน้ำ

## 3. ข่าวดี: เกณฑ์วัดการบาดเจ็บมีสำเร็จรูปแล้ว ไม่ต้องคิดเอง

วงการ automotive safety ทำไว้ให้หมดแล้ว ยืมมาใช้ได้เลย อ้างอิงได้ reviewer ยอมรับ:

| เกณฑ์ | วัดอะไร | เกณฑ์เสี่ยง |
|---|---|---|
| **HIC** (Head Injury Criterion) | บาดเจ็บศีรษะจากความเร่ง**เชิงเส้น** | HIC15 > 700 |
| **BrIC** (Brain Injury Criterion) | สมองบาดเจ็บจากการ**หมุน** ← สำคัญกับ concussion มากกว่า HIC | BrIC > 0.8 |
| **Nij** | คอบาดเจ็บ (แรงดึง/กด รวมกับโมเมนต์) | Nij > 1.0 |
| **Peak angular velocity** | นิยมในงาน concussion กีฬา | — |

> **สำหรับรักบี้ BrIC และความเร็วเชิงมุมสำคัญกว่า HIC** เพราะ concussion ในกีฬาส่วนใหญ่มาจากการหมุนของศีรษะ ไม่ใช่การกระแทกตรงๆ — จุดนี้เขียนใน discussion ได้เลย ทำให้เปเปอร์ดูรู้จริง

## 4. ข่าวดีข้อ 2: ตัวแปรต้นก็มีสำเร็จรูป

World Rugby จัดหมวดท่าปะทะไว้แล้ว ใช้เป็นกรณีศึกษาได้เลย ไม่ต้องนิยามเอง:

| ท่า | ลักษณะ |
|---|---|
| **Front-on tackle** | ปะทะตรงหน้า |
| **Side-on tackle** | ปะทะด้านข้าง |
| **From behind** | เข้าจากด้านหลัง |
| **Shoulder charge** | ใช้ไหล่กระแทกไม่กอด (ผิดกติกา) |
| **High tackle** | ปะทะเหนือไหล่ (ผิดกติกา — เป็นประเด็นร้อนของวงการ) |

> **มุมขายเปเปอร์:** เทียบเชิงปริมาณว่า high tackle เสี่ยงกว่า legal tackle กี่เท่า → ตรงกับที่ World Rugby กำลังถกเรื่องกฎพอดี ทำให้เปเปอร์มี impact

## 5. เครื่องมือ

### ❌ SolidWorks ไม่เหมาะกับงานนี้เลย

- ไม่มีระบบกล้ามเนื้อ ไม่มีโมเดลมนุษย์
- การชนคือ dynamic ไม่ใช่ static
- SolidWorks ออกแบบมาสำหรับชิ้นส่วนเครื่องกล ไม่ใช่ร่างกายมนุษย์

### ✅ ใช้ OpenSim (ฟรี)

```
โมเดลมนุษย์สำเร็จรูป (มากับ OpenSim)
  ↓  กำหนดเงื่อนไขการปะทะ: ความเร็ว มุม มวล
Forward dynamics simulation
  ↓
แรงที่ข้อ + แรงกล้ามเนื้อ + การเคลื่อนไหวของศีรษะ
  ↓  คำนวณ HIC / BrIC / Nij
ตัวเลขความเสี่ยง
  ↓  Python
Surrogate model ทำนายได้ทันที
```

| ขั้น | โปรแกรม | ฟรีไหม |
|---|---|---|
| Multibody + กล้ามเนื้อ | **OpenSim** | ✅ ฟรี |
| สคริปต์รันอัตโนมัติหลายร้อยเคส | **OpenSim Python API** (`import opensim`) | ✅ ฟรี |
| ทางเลือกเชิงพาณิชย์ | AnyBody, LS-DYNA + THUMS/GHBMC | ❌ |
| ML | Python + scikit-learn, XGBoost | ✅ ฟรี |

**โมเดลสำเร็จรูปที่ควรเริ่ม:** `Full_body_model` หรือ `gait2392` ที่มากับ OpenSim — อย่าสร้างโมเดลมนุษย์เอง เสียเวลาทั้งปี

> **สำคัญ:** ต้องรันเป็นร้อยเคส ห้ามคลิกมือทีละเคส ใช้ Python API เขียนลูปตั้งแต่วันแรก

## 6. แนวคิดหลักที่ต้องเข้าใจ

### (1) Inverse dynamics vs Forward dynamics

| | ให้อะไร | ได้อะไร | ใช้เมื่อไหร่ |
|---|---|---|---|
| **Inverse** | การเคลื่อนไหว (จากวิดีโอ/motion capture) | แรงที่ทำให้เกิดการเคลื่อนไหวนั้น | มีคลิปการแข่งจริง |
| **Forward** | แรง + เงื่อนไขเริ่มต้น | การเคลื่อนไหวที่จะเกิด | จำลองสถานการณ์สมมติ ← **คุณใช้อันนี้** |

คุณจะสมมติสถานการณ์ (ชนที่ 5 m/s มุม 30°) แล้วดูว่าเกิดอะไร → **forward dynamics**

### (2) ฟิสิกส์ของการปะทะ — 3 เรื่องที่ต้องเข้าใจ

**โมเมนตัมถ่ายเท**
```
แรงเฉลี่ย  =  การเปลี่ยนแปลงโมเมนตัม ÷ เวลาสัมผัส
F = Δp / Δt
```

**Effective mass — ตัวแปรที่คนมองข้าม**
มวลที่ "มีผลจริง" ในการชน **ไม่เท่ากับน้ำหนักตัว** ขึ้นกับท่าทาง
ผู้เล่น 100 kg ที่ท่าหลวม อาจส่ง effective mass แค่ 40 kg
ผู้เล่น 80 kg ที่เกร็งลำตัวแน่น อาจส่งได้ 70 kg
→ **นี่คือเหตุผลที่ "เทคนิคสำคัญกว่าขนาดตัว" และเป็นจุดที่เปเปอร์คุณพิสูจน์เชิงตัวเลขได้**

**ระยะเวลาสัมผัส (contact duration)**
จากสมการบน: Δt ยิ่งสั้น F ยิ่งพุ่ง
→ อุปกรณ์ป้องกันทุกชนิดทำงานด้วยหลักการเดียว: **ยืด Δt ให้นานขึ้น**

### (3) การเกร็งกล้ามเนื้อคอเปลี่ยนผลลัพธ์มหาศาล

คอเกร็ง = ศีรษะกับลำตัวกลายเป็นก้อนเดียว → effective mass ของศีรษะสูงขึ้น → ความเร่งลดลง
นี่คือตัวแปรที่ OpenSim ทำได้แต่โมเดลง่ายๆ ทำไม่ได้ → **ใส่เป็นตัวแปรต้นตัวหนึ่ง แล้วคุณจะมีของที่คนอื่นไม่มี**

## 7. ส่วน ML — คุณกำลังสร้าง Surrogate Model

### เข้าใจก่อนว่าทำไปทำไม

```
OpenSim forward simulation 1 เคส = รันหลายนาทีถึงหลายชั่วโมง
Surrogate model                   = ตอบเคสเดียวกันใน 0.1 วินาที
```

**ประโยคขายของคุณ:** "โค้ชใส่ตัวเลข 5 ตัวข้างสนาม รู้ทันทีว่าท่าปะทะนี้เสี่ยง concussion แค่ไหน"

### ออกแบบการสุ่ม — Latin Hypercube Sampling

```python
from scipy.stats import qmc

sampler = qmc.LatinHypercube(d=5, seed=42)   # 5 ตัวแปรต้น
samples = sampler.random(n=300)              # 300 เคส
cases = qmc.scale(samples, l_bounds, u_bounds)
```

ห้ามสุ่มมั่ว ห้าม full factorial (5 ตัวแปร × 10 ระดับ = 100,000 เคส รันไม่ไหว)

### ข้อมูลน้อย → ห้ามใช้ Deep Learning

| ใช้ได้ | ห้ามใช้ |
|---|---|
| **Gaussian Process Regression** ← บอก uncertainty ได้ด้วย | Deep neural network |
| XGBoost / Random Forest | CNN, Transformer |
| Polynomial response surface (baseline) | |

### 🚨 กับดักที่คุณจะพลาดแน่นอน: Data Leakage

ถ้าคุณจำลอง**ท่าเดียวกัน**หรือ**โมเดลร่างกายคนเดียวกัน** หลายสิบเคส แล้วสุ่มแบ่ง train/test ธรรมดา:

1. เคสที่คล้ายกันมากโผล่ทั้งฝั่ง train และ test
2. โมเดลแค่ "จำ" ไม่ได้เรียนรู้ฟิสิกส์
3. **ค่า R² ที่ได้คือของปลอม**

**วิธีแก้ — GroupKFold โดยกลุ่ม = ประเภทท่า tackle หรือ subject:**

```python
from sklearn.model_selection import GroupKFold, cross_val_score

groups = tackle_type      # หรือ subject_id  ← สำคัญที่สุด
cv = GroupKFold(n_splits=5)
scores = cross_val_score(model, X, y, groups=groups, cv=cv)
```

### ต้องอธิบายโมเดลได้

- **SHAP values** — ตัวแปรไหนมีผลมากสุด
- ผลต้องสอดคล้องกับฟิสิกส์: ถ้า SHAP บอก "ความเร็ว" ไม่สำคัญ แปลว่าโมเดลคุณพัง

### ต้องมี baseline

เทียบกับ linear regression ก่อนเสมอ ถ้า XGBoost ชนะแค่ 1% → ปัญหานี้ไม่ต้องใช้ ML และนั่นก็ตีพิมพ์ได้

## 11. คำศัพท์ของคุณ

| คำ | ความหมายสั้นๆ |
|---|---|
| **Multibody dynamics** | จำลองร่างกายเป็นชิ้นแข็งต่อกันด้วยข้อ |
| **Forward dynamics** | รู้แรง → ทำนายการเคลื่อนไหว |
| **Inverse dynamics** | รู้การเคลื่อนไหว → ย้อนหาแรง |
| **Joint reaction force** | แรงที่เกิดขึ้นในข้อต่อ |
| **Muscle activation** | ระดับการสั่งงานกล้ามเนื้อ (0–1) |
| **Effective mass** | มวลที่มีผลจริงในการชน ≠ น้ำหนักตัว |
| **HIC / BrIC / Nij** | เกณฑ์มาตรฐานวัดความเสี่ยงบาดเจ็บ หัว/สมอง/คอ |
| **Angular velocity** | ความเร็วการหมุนศีรษะ — ตัวชี้ concussion ที่ดี |
| **Instrumented mouthguard** | ฟันยางติดเซ็นเซอร์ วัดความเร่งศีรษะนักกีฬาจริง |
| **Surrogate model** | โมเดลเร็วที่ใช้แทนการจำลองที่ช้า |
| **LHS** | วิธีสุ่มพารามิเตอร์ให้กระจายทั่วด้วยจำนวนน้อย |
| **Data leakage** | ข้อมูลทดสอบรั่วเข้าชุดฝึก → ผลลัพธ์ปลอม |
| **SHAP** | ค่าที่บอกว่าตัวแปรไหนมีผลต่อคำทำนายเท่าไหร่ |
